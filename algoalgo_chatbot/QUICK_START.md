# ⚡ 스터디 출석 봇 - 5분 설치 가이드

## 🚀 빠른 시작 (3단계)

### Step 1️⃣: 디스코드 봇 생성 (2분)

1. https://discord.com/developers/applications 접속
2. "New Application" 클릭 → 이름 입력 (예: "스터디봇")
3. "Bot" 탭 → "Add Bot" 클릭
4. "TOKEN" 섹션의 "Copy" 클릭
   - ⚠️ **절대 공개하지 말 것!**
5. "OAUTH2" → "URL Generator" 클릭
   - Scopes: `bot` 체크
   - Permissions: `Send Messages`, `Read Messages/View Channels`, `Embed Links` 체크
   - 생성된 URL 복사 & 열기
   - 봇 추가할 서버 선택

**✅ 완료!**

---

### Step 2️⃣: 코드 설정 (1분)

`study_attendance_bot.py` 파일을 열고 맨 아래 수정:

**수정 전:**
```python
if __name__ == "__main__":
    TOKEN = "YOUR_BOT_TOKEN_HERE"  # 👈 여기
    bot.run(TOKEN)
```

**수정 후:**
```python
if __name__ == "__main__":
    TOKEN = "MzY3NzI1NzM5MTUzNzAwMzUz.DLrGYQ.Ovy4MCQywSkoM..."  # 👈 토큰 붙여넣기
    bot.run(TOKEN)
```

**✅ 완료!**

---

### Step 3️⃣: 실행 (1분)

```bash
# 1. 라이브러리 설치
pip install discord.py

# 2. 봇 실행
python study_attendance_bot.py
```

**출력 예시:**
```
YourBotName#1234 로그인 성공!
봇이 준비되었습니다.
```

**✅ 완료! 디스코드에서 봇이 온라인 상태가 됨**

## ❓ 자주 묻는 질문

### Q: 시간 형식이 뭐야?
A: 정수(2, 3) 또는 소수(2.5, 3.5) 모두 가능
```
!출석 2      # 2시간
!출석 2.5    # 2시간 30분
!출석 3      # 3시간
```

### Q: 내용을 여러 줄로 쓸 수 있어?
A: 한 줄에 모두 써야 함
```
!출석 2 파이썬 강의 복습, 알고리즘 문제 풀이, 복잡도 분석
```

### Q: 기록을 삭제하고 싶어
A: 현재는 불가능 (관리자가 특정 사용자 초기화는 가능)
```
!출석수정 2024-01-15  # 이렇게 수정 가능
```

### Q: 모바일에서도 됩니까?
A: 네! 디스코드 모바일 앱에서도 동일하게 사용 가능

### Q: 데이터가 클라우드에 저장되나?
A: 아니오. 봇이 실행 중인 컴퓨터의 `study_data.json`에 저장됨
- PC 24시간 켜야 함 또는
- 클라우드 서버에 배포 추천 (Replit, Railway 등)
