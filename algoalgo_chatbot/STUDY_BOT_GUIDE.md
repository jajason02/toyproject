## 기본 사용법

### 📌 필수 출석 요건
- **2시간 이상 공부**해야 하루 출석으로 인정
- 원하면 더 많은 시간 기록 가능 (예: 3시간, 4시간)

### 💡 기본 개념
- **일일 기록**: 매일 한 번씩 출석 가능
- **시간 기록**: 그날 공부한 시간 기록
- **학습 내용**: 그날 뭘 했는지 짧게 기록

## 출석 기록 명령어

### 1. `!출석` - 오늘 출석 기록

#### 기본 사용법
```
!출석
```
- 2시간 (기본값) 자동 기록
- 내용: "기록 없음"

#### 시간과 함께 기록
```
!출석 2.5
```
- 2.5시간 공부 기록

#### 시간과 내용 함께 기록 ⭐ (추천)
```
!출석 2 파이썬 강의 복습, 알고리즘 문제 풀이
```

```
!출석 3 리액트 프로젝트 진행 - TodoList 컴포넌트 완성
```

```
!출석 2.5 CS 스터디 - 메모리 구조, 포인터 개념 정리
```

#### 응답 예시
```
✅ 출석 완료
👤 이름: john_doe
📅 날짜: 2024-01-15
⏰ 공부 시간: 2시간
📝 오늘 할 일: 파이썬 강의 복습, 알고리즘 문제 풀이
시간: 14:23:45
```

---

### 2. `!출석수정` - 기록 수정

#### 오늘 기록 수정
```
!출석수정 3 더 많이 공부했어!
```

#### 특정 날짜 기록 수정
```
!출석수정 2024-01-15 3.5 시간 수정, 내용도 수정
```

---

### 3. `!오늘기록` - 오늘 기록 확인

#### 자신의 기록 확인
```
!오늘기록
```

#### 다른 사람의 기록 확인
```
!오늘기록 @john_doe
```

## 통계 및 조회 명령어

### 📊 개인 통계

#### 1. `!개인통계` - 전체 통계
```
!개인통계
```
- 총 출석일: 15일
- 총 공부시간: 32시간
- 평균 시간/일: 2.1시간

#### 2. `!주간통계` - 이번주 통계
```
!주간통계
```
- 월 ~ 일의 기록 표시
- 요일별 시간과 내용 표시

예시 응답:
```
📅 john_doe님의 이번주 통계 (01-08 ~ 01-15)
📊 출석일: 5일
⏰ 총 시간: 11시간
📝 상세 기록
**2024-01-08 (월)**: 2시간 - 파이썬 강의 복습
**2024-01-09 (화)**: 2.5시간 - 알고리즘 문제 풀이
...
```

#### 3. `!월간통계` - 월간 통계
```
!월간통계                    # 이번 달
!월간통계 2024-01           # 특정 달
!월간통계 2024-01 @john_doe # 특정 사람 특정 달
```

예시:
```
📊 john_doe님의 2024-01 통계
📅 출석일: 20일
⏰ 총 시간: 45시간
📈 평균 시간/일: 2.3시간
```

---

### 📚 학습 기록

#### `!학습기록` - 최근 N일의 상세 기록
```
!학습기록          # 최근 7일 (기본값)
!학습기록 30       # 최근 30일
!학습기록 14 @john_doe  # 특정 사람 최근 14일
```

예시 응답:
```
📚 john_doe님의 최근 7일 학습 기록

**2024-01-15** ⏰2h
📝 파이썬 강의 복습, 알고리즘 문제 풀이

**2024-01-14** ⏰2.5h
📝 리액트 프로젝트 진행 - TodoList 컴포넌트 완성

**2024-01-13** ⏰2h
📝 CS 스터디 - 메모리 구조, 포인터 개념 정리
```

## 관리자 명령어

### 👨‍💼 관리자만 사용 가능

#### 1. `!전체주간통계` - 이번주 전체 순위
```
!전체주간통계
```

예시:
```
📅 이번주 전체 통계 (01-08 ~ 01-15)

🥇 **john_doe**: 12시간 (6일, 평균 2.0h)
🥈 **jane_smith**: 11시간 (5일, 평균 2.2h)
🥉 **bob_wilson**: 10시간 (5일, 평균 2.0h)
4️⃣ **alice_kim**: 8시간 (4일, 평균 2.0h)

총 참여자: 4명
```

#### 2. `!전체월간통계` - 월간 전체 순위
```
!전체월간통계          # 이번 달
!전체월간통계 2024-01  # 특정 달
```

예시:
```
📊 2024-01 전체 통계

🥇 **john_doe**: 45시간 (20일, 평균 2.3h)
🥈 **jane_smith**: 42시간 (18일, 평균 2.3h)
🥉 **bob_wilson**: 40시간 (17일, 평균 2.4h)
```

#### 3. `!출석현황` - 특정 날짜 전체 출석 현황
```
!출석현황              # 오늘
!출석현황 2024-01-15   # 특정 날짜
```

예시:
```
📋 2024-01-15 출석 현황

🥇 **john_doe**: 2시간 - 파이썬 강의 복습, 알고리즘
🥈 **jane_smith**: 2.5시간 - 리액트 프로젝트 진행
🥉 **bob_wilson**: 2시간 - CS 스터디

총 3명 출석
```

## 🎯 사용 팁

### 1️⃣ 효과적인 출석 기록 방법
```
좋은 예:
!출석 2.5 Python 함수형 프로그래밍 강의 + 연습문제 10개

나쁜 예:
!출석 2 공부함

좋은 예:
!출석 3 React 프로젝트 - 사용자 인증 기능 구현 완료

나쁜 예:
!출석 3 일 함
```

### 2️⃣ 주간/월간 계획 확인
```
매주 월요일:
!전체주간통계  # 지난주 순위 확인

매달 1일:
!전체월간통계 2023-12  # 지난달 통계 확인
```

### 3️⃣ 장기 진행 추적
```
!개인통계              # 전체 성과 확인
!학습기록 30           # 최근 한 달 기록 검토
!월간통계 2024-01      # 월별 성장 추적
```

## 🐛 문제 해결

### 1. "오늘 이미 출석하셨습니다" 메시지
- 하루에 한 번씩만 출석 가능
- 기록 수정하려면: `!출석수정 [시간] [내용]` 사용

### 2. 명령어가 작동하지 않음
- 명령어 앞에 `!` 있는지 확인
- 스페이스 정확한지 확인
- 예: `!출석 2 내용` (O), `!출석2내용` (X)

### 3. 내용이 저장되지 않음
- 내용에 특수문자 사용해도 됨
- 큰따옴표, 작은따옴표 필요 없음
- 예: `!출석 2 C++ 스터디 - 포인터 & 메모리` (OK)
