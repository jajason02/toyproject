# Arctic 발표 — 페이지별 말할 내용

**13회차 관통 프로젝트 · 박재현 · 문성웅 · 박준성** / 발표 15분 이내

---

## 1p. 표지
- 서비스명 Arctic, 한 줄 소개: 읽고·쓰고·나누는 AI 도서 커뮤니티
- 팀원 3인 소개

## 2p. 문제 정의
- 요즘 20대가 책을 정말 안 읽는다. 1년에 1권 읽을까 말까 한 수준
- 그에 반해 블로그·유튜브·SNS 등으로 본인을 표현하고자 하는 욕망이 있는 사람은 많다
- 시장에는 "무엇을 읽을까"를 돕는 서비스는 많아도 "어떻게 쓸까"를 돕는 곳은 없다
- 이 서비스를 통해 창작욕이 있는 사람에게는 책을, 책을 좋아하던 사람에게는 창작을 추천하고 싶다
- 독자와 작가를 한 흐름으로 연결

## 3p. 서비스 한눈에 (목차만)
- 주요 기능 3가지: ① 커뮤니티 ② 추천 ③ AI 창작
- ③ AI 창작이 핵심 차별점

## 4p. 커뮤니티
- 책에 대한 의견을 교환하는 커뮤니티 (도서 리뷰 · 좋아요)
- 자유 스레드로 자유롭게 소통
- AI로 만든 창작물 공유
- 책 정보를 확인하고, 안 본 책은 위시리스트에, 본 책 중 마음에 드는 책은 내 책장에 담을 수 있다

## 5p. 추천
- 내 취향 + 내가 팔로우한 사람들의 취향을 고려하여 추천
- 예상 별점도 함께 도출

## 6p. AI 창작 — 아이디어 발상
- 장르와 키워드만 정하면 AI가 아이디어 발상을 함께 시작
- 예: SF 장르 + "고독, 우주" 키워드

## 7p. AI 창작 — 창작 사이클
- 흐름: 아이디어 발상 → 플롯 제안 → 저장 → 공유
- 아이디어를 생성하고, 그 아이디어를 바탕으로 플롯까지 발전시켜 저장
- 저장한 창작물은 공유 가능. 내 창작물은 공개·비공개 선택, 다른 사람들의 창작물도 열람 가능

## 8p. AI 구현 (코드·프롬프트, 짧게)
- 화면은 아이디어 생성 부분. 같은 방식으로 댓글 요약·플롯 생성·문장 교정 기능에도 동일하게 프롬프트·코드를 구현했다
- 장르·키워드: 사용자 입력을 그대로 프롬프트에 주입해 맥락 구체화
- 가드레일: 창작 외 요청을 차단하는 시스템 프롬프트
- JSON 응답: 제목·핵심 전제·등장인물·시공간·갈등을 구조화해 반환
- async: FastAPI 비동기 호출로 타임아웃·파싱 오류 처리

## 9p. 라이브 시연
- 흐름: 로그인 → 추천 → AI 창작 → 공유

## 10p. 기술 스택
- 스택: Vue 3 / Django REST / FastAPI / SQLite / OpenAI API
- 핵심: AI 추론 서버를 FastAPI로 분리
- 이유: AI 호출은 GMS를 활용하기 때문에 오래 걸린다
- Django 서버 하나만 쓰면, AI 호출이 들어왔을 때 그 작업이 끝날 때까지 다른 작업을 하지 못하는 병목이 생긴다
- FastAPI로 분리 → AI 호출을 처리하면서도 Django 서버가 다른 일을 할 수 있게 함

## 11p. 팀과 협업
- 재현(팀장) ai / AI 서버·인프라
- 성웅 accounts / 인증·추천
- 준성 books / 리뷰·커뮤니티
- Git Flow 브랜치 전략으로 분업, 병합 충돌이 나지 않게 주의
- 기능이 일부 혹은 완료될 때마다 미팅으로 서로 피드백하고 다음 작업을 지정, 주기적으로 개선·수정하며 애자일 방법론 적용
- (아이스브레이킹) 초반에 개고생했다. 3명이 2명보다 조율할 게 많아 더 힘든 것 같다

## 12p. 트러블슈팅
- ① DB 충돌: 브랜치 병합 과정에서 Django가 db_table 없이 테이블을 자동 생성(앱_모델, 소문자) → ERD 기준(BOOK)과 안 맞아 충돌 / 해결: 각 모델 Meta에 db_table 명시해 스키마 통일
- ② 인증: localStorage에 토큰을 보관하니 창을 닫았다 들어오거나 서버를 껐다 켜도 로그인이 유지됨 → 의도와 달랐다 / 해결: sessionStorage로 변경, 창·탭을 닫으면 자동 로그아웃

## 13p. 마무리
- 배운 점: 3인 협업으로 형상관리·버전관리 과정을 제대로 경험
- 다음 단계: DB를 이관하고 서버에 배포해 트래픽 관리까지 다뤄보고 싶다
- 마무리 멘트: Arctic이 창작활동의 북극항로가 되겠습니다
